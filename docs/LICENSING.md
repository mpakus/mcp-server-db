## Source-available terminology

Commercial-use restrictions do not meet the
[Open Source Definition](https://opensource.org/osd), which permits use in any
field, including business. We therefore describe this project's restricted
license as source-available. Free use by a qualifying open-source project is
separate from claiming that this license itself is OSI-approved.

The unmodified standard text comes from the
[PolyForm Project](https://polyformproject.org/licenses/noncommercial/1.0.0).
The scope and commercial offering should receive legal review before a release
or commercial agreement is published; this documentation is not a signed
commercial contract or an ownership audit.
